# blocks — 블록 렌더러

「문서 JSON → 화면」만 책임지는 모듈이 여기에 온다. 화면 모드와 인쇄 모드를 같은 렌더러가 처리하고,
공개 페이지·제안서·미리보기·PDF 인쇄 레이아웃이 모두 이 렌더러를 쓴다.

- 시험 경계: Vitest + Testing Library로 문서 JSON을 넣고 렌더링 결과를 본다(`*.test.tsx`를 옆에 둔다).
- 예시 문서 픽스처(가나다상사 제안서를 블록 JSON으로 옮긴 것)는 백엔드 시험과 함께 쓴다.
  첫 블록 티켓이 위치를 정한다(저장소 루트 `fixtures/` 같은 공유 자리).
